# ¿Esta obra se va a prorrogar?

App que estima, el día de la firma, el riesgo de prórroga de un contrato de obra pública en SECOP II, explica por
qué, revisa el tope de adiciones de la Ley 80 y resume las causas de las prórrogas. Combina reglas, machine learning
(regresión logística) y un modelo de lenguaje (Claude Haiku 5.5).

Proyecto final de Herramientas de Inteligencia Artificial (ICYA3004), Universidad de los Andes, 2026-20.
Luis Miguel Gutiérrez Gallego e Ivan Leon Ibarra Freyle.

Datos: datos abiertos de SECOP II (datos.gov.co), ya procesados. Para correrla en un computador:
`pip install -r requirements.txt` y luego `streamlit run app.py`.
